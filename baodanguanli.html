🔑 GitHub Token 配置（冷备份专用）

仅用于冷备份，不配置 Token 不影响 Supabase 主同步使用。
请前往 GitHub Token设置页 创建一个 Tokens (classic)，勾选 repo 权限后粘贴到下方。
Token 将加密存储在您的浏览器本地，不会上传到任何第三方。

⚡ Supabase 云端同步（已启用，硬编码配置）

工作原理：通过 Supabase Auth（邮箱+密码）登录后，自动开启实时同步。
数据按 auth.uid()（您的账号唯一UUID）行级隔离，配合 RLS 策略其他用户无法访问您的行。
登录账户、密码、个人信息保存在 Supabase Auth 服务端（bcrypt 加密），任何人（包括管理员）都无法看到您的明文密码。
显示名称：注册时填写，用于页面顶部显示（非登录名，可随意）。

💡 导入提示：「智能模式」支持预览解析结果、灵活列名匹配（可自定义中文列名，如「姓名/手机/保单号/有无分红」均可识别，且不会串列）、合并去重三种策略（覆盖 / 合并更新 / 仅新增不覆盖）。普通导入同样支持智能列名匹配，但会直接覆盖当前数据。
📋 模板说明：Excel模板现已覆盖全部信息（37列）：客户基础信息 + 个人/家庭情况画像 + 家庭成员 + 保单全字段（含满期日期、是否有分红）+ 生存金（类型/金额/起领/领取记录）。无保单的纯客户资源行，保单代码与险种名称留空即可。点击「导出Excel模板」可查看含填写说明的完整模板。
✍️ 填写技巧：日期支持 20230115 / 2023-01-15 / 2023年1月15日 / Excel日期 等多种格式；金额可含千分位（如 12,000）；同一客户多张保单写成多行（姓名相同自动合并）；家庭成员格式：姓名|关系|身份证|电话|备注，多人用分号分隔。
