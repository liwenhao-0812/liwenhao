🔑 GitHub Token 配置

为实现数据云端同步，需要配置您的 GitHub Personal Access Token。
请前往 GitHub Token设置页 创建一个 Tokens (classic)，勾选 repo 权限后粘贴到下方。
Token 将加密存储在您的浏览器本地，不会上传到任何第三方。

⚡ Supabase 实时同步（推荐）

使用 Supabase 实现跨设备实时数据同步，电脑端修改后手机端自动刷新。
请前往 supabase.com 注册并创建项目，在项目 Settings → API 中获取 Project URL 和 anon public key。
然后在项目的 SQL Editor 中执行 迁移脚本 创建数据库表。
